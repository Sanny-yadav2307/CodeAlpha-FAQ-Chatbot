# 🤖 CodeAlpha FAQ Assistant

An Intelligent FAQ Chatbot built for **CodeAlpha AI Internship (Task 2)** using **Natural Language Processing (NLP)**.

## 🚀 Features
- 🧠 **TF-IDF Vectorization** for text feature extraction.
- 🎯 **Cosine Similarity** for accurate FAQ matching.
- 🎨 **Modern Streamlit UI** with custom styling and sidebar controls.

## 🛠️ Tech Stack
- Python 🐍
- Streamlit 🎈
- Scikit-learn 📊
